Fonksiyon iskeleti: boşluğu doldur

Alıştırmalarda sık göreceğin def ve return kalıbını tanır, hazır iskeletin içini doldurursun. Ayrıntısı Fonksiyonlar dersinde.

Uygulamada aç, 10 alıştırmayı çözÜcretsiz, hesap gerekmez, kurulum yok.

Alıştırmaların çoğu senden küçük bir fonksiyon (function) ister, çünkü testler fonksiyonu çağırıp sonucu denetler. Şimdilik tüm kuralları bilmen gerekmez: hazır bir kalıbın boşluğunu doldurmak yeter.

def kdvli(tutar):
    sonuc = tutar * 1.2
    return sonuc

print(kdvli(100))
  • def kdvli(tutar): "kdvli adında bir iş tanımlıyorum, ona bir tutar verilecek" demek. Satır iki noktayla biter.
  • Alttaki satırlar dört boşluk içeride yazılır. Fonksiyonun gövdesi budur.
  • return sonuc sonucu çağırana geri verir ve fonksiyonu bitirir.
  • kdvli(100) fonksiyonu çağırır: tutar o çağrıda 100 olur.

return ile print aynı şey değil

print ekrana yazar, değer geri vermez. return değeri geri verir, ekrana yazmaz. Testler return ile verdiğin değere bakar.

def yazdir(x):
    print(x * 2)

def dondur(x):
    return x * 2

a = yazdir(5)     # ekrana 10 yazar, a boş kalır (None)
b = dondur(5)     # ekrana bir şey yazmaz, b 10 olur
print(a, b)

def indirimli(fiyat):

Birden çok değer alan fonksiyonda parametreler virgülle ayrılır: def topla(a, b):. Fonksiyonlar dersinde varsayılan değerleri, kapsamı ve daha fazlasını göreceksin.
