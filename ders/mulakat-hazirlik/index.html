Algoritma soruları: kalıpları tanı

Mülakat sorularının büyük kısmı beş altı kalıba iner. Soruyu duyunca kalıbı tanırsan çözümün yarısı bitmiştir.

1. Sözlükle sayım ve arama: iki toplam

"Listede toplamı hedef eden iki elemanın indekslerini bul." Kaba yol çift döngü, O(n²). Akıllı yol: gördüğün her sayıyı sözlüğe koy, sıradaki sayının tamamlayıcısı (hedef - sayı) sözlükte mi diye bak. Tek geçiş, O(n).

def iki_toplam(sayilar, hedef):
    gorulen = {}                       # değer -> indeks
    for i, s in enumerate(sayilar):
        kalan = hedef - s
        if kalan in gorulen:
            return [gorulen[kalan], i]
        gorulen[s] = i
    return []

fiyatlar = [250, 90, 410, 160, 300]
print(iki_toplam(fiyatlar, 500))   # 250 + 250 yok; 90 + 410 -> [1, 2]
print(iki_toplam(fiyatlar, 1000))  # []

Aynı kalıp "anagram grupları"nda anahtarı sıralanmış harfler yaparak, "en çok tekrar eden ürün"de Counter ile görünür. Soru "bul, say, grupla" diyorsa sözlük düşün.

2. Küme ile O(n): en uzun ardışık dizi

"Sırasız sayılarda en uzun ardışık sayı dizisinin uzunluğu?" Sıralamak O(n log n). Küme ile O(n): her sayı için, bir eksiği kümede yoksa bu bir dizinin başıdır; ileri say.

def en_uzun_ardisik(sayilar):
    kume = set(sayilar)
    en_iyi = 0
    for s in kume:
        if s - 1 not in kume:          # yalnızca dizi başlarından say
            n = 1
            while s + n in kume:
                n += 1
            en_iyi = max(en_iyi, n)
    return en_iyi

print(en_uzun_ardisik([100, 4, 200, 1, 3, 2]))   # 1,2,3,4 -> 4

Neden O(n)? Her sayı yalnızca ait olduğu dizinin başından itibaren bir kez sayılır. Mülakatçı "neden while içinde while var ama O(n)?" diye sorar; cevap bu.

3. Kayan pencere (sliding window)

"Art arda k günün en yüksek toplam cirosu" ya da "tekrarsız en uzun alt dize." Sabit ya da esneyen bir pencereyi sağa kaydırırsın; giren elemanı ekler, çıkanı çıkarırsın. Her adımda yeniden toplamak O(n·k); pencereyle O(n).

def en_iyi_pencere(ciro, k):
    toplam = sum(ciro[:k])
    en_iyi, bas = toplam, 0
    for i in range(k, len(ciro)):
        toplam += ciro[i] - ciro[i - k]
        if toplam > en_iyi:
            en_iyi, bas = toplam, i - k + 1
    return bas, en_iyi

gunluk = [120, 300, 80, 450, 200, 90, 310]
print(en_iyi_pencere(gunluk, 3))   # (1, 830): 300+80+450

4. İki pointer ve ikili arama

Sıralı veride iki uçtan ortaya yürümek (iki pointer) ya da ortadan ikiye bölmek (ikili arama, O(log n)) klasik kalıplardır. bisect modülü ikili aramayı hazır verir ama mülakatta elle yazmanı isterler: lo, hi sınırları ve mid hesabı; döngü lo <= hi sürdükçe.

def ikili_ara(sirali, hedef):
    lo, hi = 0, len(sirali) - 1
    while lo <= hi:
        mid = (lo + hi) // 2
        if sirali[mid] == hedef:
            return mid
        if sirali[mid] < hedef:
            lo = mid + 1
        else:
            hi = mid - 1
    return -1

print(ikili_ara([3, 8, 15, 21, 42, 57], 21))   # 3
print(ikili_ara([3, 8, 15, 21, 42, 57], 22))   # -1

5. BFS: en kısa yol

Grafta "A'dan B'ye en az kaç adım?" sorusunda genişlik öncelikli arama (BFS) kullanılır: kuyruk (collections.deque) ve ziyaret edilenler kümesi. Depo ağı, sosyal bağlantı, kelime merdiveni; hepsi aynı kalıp.

from collections import deque

depolar = {
    "İstanbul": ["Bursa", "Kocaeli"],
    "Bursa": ["İstanbul", "Eskişehir"],
    "Kocaeli": ["İstanbul", "Ankara"],
    "Eskişehir": ["Bursa", "Ankara"],
    "Ankara": ["Kocaeli", "Eskişehir"],
}

def en_kisa_adim(graf, bas, hedef):
    kuyruk = deque([(bas, 0)])
    ziyaret = {bas}
    while kuyruk:
        dugum, adim = kuyruk.popleft()
        if dugum == hedef:
            return adim
        for komsu in graf.get(dugum, []):
            if komsu not in ziyaret:
                ziyaret.add(komsu)
                kuyruk.append((komsu, adim + 1))
    return -1

print(en_kisa_adim(depolar, "İstanbul", "Ankara"))   # 2
Ziyareti kuyruğa eklerken işaretleKuyruktan çıkarırken işaretlersen aynı düğüm kuyruğa birden çok kez girer; büyük grafta süre patlar. Kümeye ekleme anı, kuyruğa ekleme anıyla aynı olmalı.

Karmaşıklık: Big-O konuşabilmek

Her çözümden sonra mülakatçı "karmaşıklığı ne?" diye sorar. Kısa sözlük: sözlük/küme erişimi O(1) ortalama; listede arama O(n); sıralama O(n log n); çift döngü O(n²); ikili arama O(log n); BFS O(V + E). Bellek için de aynı soru gelir: ek sözlük tutuyorsan O(n) bellek. "Daha iyisi var mı?" sorusuna, mümkünse "hayır, çünkü her elemana en az bir kez bakmak gerekir" gibi bir alt sınır argümanı ver.

Python'a özgü püf noktalarin listede O(n), kümede O(1). String birleştirmede döngüde += yerine liste toplayıp "".join. list.pop(0) O(n), deque.popleft() O(1). Bunları söylemek "dili biliyor" izlenimi verir.

Canlı kodlama ipuçları

  1. Soruyu tekrar et ve netleştir: Girdi boş olabilir mi? Negatif sayı var mı? Tekrar eden eleman? Çıktı indeks mi değer mi? Her soru bir puan.
  2. Küçük bir örnek yaz: 4-5 elemanlı girdi ve beklenen çıktı. Örnek olmadan kod yazma.
  3. Önce kaba çözümü söyle: "Çift döngüyle O(n²) olur; sözlükle O(n)'e indirebilirim." Mülakatçı düşünme sürecini görmek ister.
  4. Sesli düşün, sessiz yazma: Takıldığında "burada iki seçenek var" de. Sessizlik en kötü sinyaldir.
  5. Yazdıktan sonra örnekle izle: Kodu satır satır örnek üzerinde yürüt. Kenar durumları (boş, tek eleman, hepsi aynı) kontrol et.
  6. Karmaşıklığı kendin söyle: Sorulmadan "zaman O(n), bellek O(n)" de.
  7. Temiz ad ve küçük fonksiyon: a, b, tmp yerine gorulen, kalan. Test edilebilir fonksiyon yaz, print ile değil return ile sonuç ver.

1. Yığın: son giren ilk çıkar

Parantez doğrulama en klasik yığın sorusudur. Bir adım ötesi monoton yığındır: "her gün için fiyatın kaç gün sonra yükseleceğini bul" gibi sorularda, henüz cevabı bulunmamış günlerin indekslerini azalan sırada yığında tutarsın. Her indeks bir kez girip bir kez çıktığı için toplam O(n) olur.

def gecerli_mi(ifade):
    eslesme = {")": "(", "]": "[", "}": "{"}
    yigin = []
    for c in ifade:
        if c in "([{":
            yigin.append(c)
        elif c in eslesme:
            if not yigin or yigin.pop() != eslesme[c]:
                return False
    return not yigin

print(gecerli_mi("{[()()]}"), gecerli_mi("([)]"), gecerli_mi("(("))

def kac_gun_sonra(fiyat):
    sonuc = [0] * len(fiyat)
    yigin = []                          # cevabı bekleyen günlerin indeksleri
    for i, f in enumerate(fiyat):
        while yigin and fiyat[yigin[-1]] < f:
            j = yigin.pop()
            sonuc[j] = i - j
        yigin.append(i)
    return sonuc

print(kac_gun_sonra([73, 74, 75, 71, 69, 72, 76, 73]))

2. Heap: en büyük k ve ağırlıklı en kısa yol

heapq en küçük elemanı her zaman h[0]'da tutan bir min-heap'tir; ekleme ve çıkarma O(log n). "En büyük k" için boyutu k olan bir min-heap tut: yeni eleman tepedekinden büyükse değiştir. Böylece n elemanı O(n log k)'da tararsın; heapq.nlargest bunu hazır yapar. Max-heap gerekiyorsa değerleri eksiyle çarparak koy. Dijkstra algoritması da heap'e dayanır: her adımda en yakın düğümü çıkarırsın.

import heapq

siparisler = [("S1", 420), ("S2", 90), ("S3", 1250), ("S4", 610), ("S5", 300)]
print(heapq.nlargest(2, siparisler, key=lambda s: s[1]))

def dijkstra(graf, bas):
    mesafe = {bas: 0}
    h = [(0, bas)]
    while h:
        d, u = heapq.heappop(h)
        if d > mesafe.get(u, float("inf")):
            continue                     # eski, geçersiz kayıt
        for v, w in graf.get(u, []):
            yeni = d + w
            if yeni < mesafe.get(v, float("inf")):
                mesafe[v] = yeni
                heapq.heappush(h, (yeni, v))
    return mesafe

yollar = {"Depo": [("Kadıköy", 12), ("Beşiktaş", 7)],
          "Beşiktaş": [("Kadıköy", 3), ("Şişli", 4)],
          "Kadıköy": [("Ataşehir", 6)], "Şişli": [("Ataşehir", 15)]}
print(dijkstra(yollar, "Depo"))

4. Dinamik programlama

İki işaret ara: optimal alt yapı (büyük problemin cevabı küçüklerinkinden kurulur) ve örtüşen alt problemler (aynı küçük problem tekrar tekrar çözülür). İki yazım şekli vardır: yukarıdan aşağı (özyineleme + functools.cache) ve aşağıdan yukarı (tablo). Mülakatta önce özyinelemeli tanımı söyle, sonra tabloya çevir.

from functools import cache

def para_ustu(bozuklar, tutar):
    """En az kaç bozuk para? Mümkün değilse -1."""
    SONSUZ = float("inf")
    dp = [0] + [SONSUZ] * tutar          # dp[t]: t tutarı için en az para
    for t in range(1, tutar + 1):
        for b in bozuklar:
            if b <= t and dp[t - b] + 1 < dp[t]:
                dp[t] = dp[t - b] + 1
    return dp[tutar] if dp[tutar] != SONSUZ else -1

print(para_ustu([1, 5, 10, 25], 63), para_ustu([5, 10], 3))

@cache
def yol_sayisi(satir, sutun):
    """Izgarada sol üstten sağ alta yalnız sağ/aşağı giderek kaç yol?"""
    if satir == 1 or sutun == 1:
        return 1
    return yol_sayisi(satir - 1, sutun) + yol_sayisi(satir, sutun - 1)

print(yol_sayisi(3, 7), yol_sayisi.cache_info().hits)
Açgözlü yaklaşım tuzağıPara üstünde "her seferinde en büyük parayı al" (greedy) TL/kuruş gibi sistemlerde doğru çalışır ama [1, 3, 4] ile 6 için 4+1+1 (3 para) verir; doğrusu 3+3 (2 para). Mülakatçı tam bu karşı örneği sorar: greedy önerirsen neden doğru olduğunu kanıtlamaya hazır ol.

5. Geri izleme ve aralıklar

Geri izleme, seçim yap, özyinele, seçimi geri al döngüsüdür. "Toplamı hedef olan tüm kombinasyonlar" ya da "tüm alt kümeler" bu kalıptır; dalı erken kesmek (pruning, ör. sıralı adaylarda toplam aşınca break) süreyi ciddi biçimde düşürür. Aralık sorularında ise neredeyse her zaman ilk adım başlangıca göre sıralamaktır.

def birlestir(araliklar):
    sonuc = []
    for bas, bit in sorted(araliklar):
        if sonuc and bas <= sonuc[-1][1]:
            sonuc[-1][1] = max(sonuc[-1][1], bit)
        else:
            sonuc.append([bas, bit])
    return sonuc

print(birlestir([(9, 11), (1, 3), (2, 6), (8, 10), (15, 18)]))

def alt_kumeler(ogeler):
    sonuc, secim = [], []
    def gez(i):
        if i == len(ogeler):
            sonuc.append(secim.copy())   # kopyala: secim değişmeye devam edecek
            return
        secim.append(ogeler[i]); gez(i + 1)   # al
        secim.pop();             gez(i + 1)   # alma (geri al)
    gez(0)
    return sonuc

print(alt_kumeler(["çay", "simit", "peynir"]))

Canlı kodlama problemi (25 dakika)

Görev: "Sipariş akışında her sipariş (musteri_id, zaman_sn) olarak geliyor. Son 60 saniyede 3'ten fazla sipariş veren müşterileri, sınırı ilk aştıkları an itibarıyla raporla." Takip sorusu: "Akış sıralı gelmiyorsa ne değişir? Bellek sınırlıysa?"

from collections import defaultdict, deque

def supheliler(siparisler, pencere=60, sinir=3):
    son = defaultdict(deque)          # müşteri -> penceredeki zamanlar
    bulunan = {}
    for musteri, t in siparisler:     # zaman sırasıyla geldiğini varsayıyoruz (netleştir!)
        q = son[musteri]
        q.append(t)
        while q[0] <= t - pencere:    # pencereden çıkanları at
            q.popleft()
        if len(q) > sinir and musteri not in bulunan:
            bulunan[musteri] = t
    return bulunan

akis = [(7, 0), (7, 10), (9, 12), (7, 30), (7, 55), (9, 70), (7, 61), (7, 62)]
print(supheliler(akis))

Değerlendirme ölçütleri: Soruyu netleştirdin mi (pencere dahil mi, sıralı mı)? Kaba çözümü söyleyip (her siparişte tüm geçmişi taramak, O(n²)) iyileştirdin mi? Karmaşıklığı söyledin mi (her zaman en fazla bir kez eklenip çıkarılır: O(n) zaman, O(müşteri × pencere) bellek)? Kenar durumları denedin mi (aynı saniyede sipariş, tam 60 saniye sınırı)?

Uzmanlaş

Soruyu kalıba indirgeme pratiği

Her gün bir soru çöz ve çözümden sonra şu üç satırı yaz: kalıp (sözlük / küme / pencere / iki pointer / ikili arama / BFS-DFS / dinamik programlama), karmaşıklık, kenar durumları. Bir ay sonra soruları duyar duymaz kalıbı göreceksin. Dinamik programlama (en uzun ortak alt dizi, para üstü) ve heap (en büyük k eleman, heapq.nlargest) bu dersin kapsamı dışında kalan ama sık sorulan iki kalıptır; sırada onlar olsun.

Yanlış ama sık verilen cevaplar

"GIL Python'ı tek çekirdekli yapar" (yanlış: multiprocessing ve C uzantıları çekirdekleri kullanır). "Tuple değişmezdir, içi de değişmez" (yanlış: tuple içindeki liste değişir). "Decorator yalnızca loglama içindir" (eksik: önbellek, yetki, yeniden deneme, kayıt). "is daha hızlıdır, hep onu kullan" (yanlış: kimlik ile eşitlik farklı sorulardır; küçük tamsayı önbelleği yanıltır).
